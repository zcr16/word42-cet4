## 适合本次学习起点的默认安排

高考英语成绩只能提供粗略背景，不能换算为词汇量。本应用先通过20个基础词自测发现缺口，再按下面的渐进目标学习：

| 时间 | 新词目标 | 写作训练重点 |
| --- | --- | --- |
| 第1–5天 | 每天10词 | 读懂句子，找主干和关键词 |
| 第6–15天 | 每天15词 | 替换词语，仿写简单句 |
| 第16–35天 | 每天20词 | 补全段落，逐步独立写作 |
| 第36–42天 | 集中复习 | 错题回炉，完整限时训练 |

在没有跳过词、补漏词和漏学的情况下，第35天完成600个主学词。700个重点词中的另100词可以在词条详情加入计划。基础自测答错的词也会加入计划，可能延长新词阶段；漏学词不会消失，42天后仍可继续。

建议每天分两到三段：先清理到期复习，再学习新词，最后做少量句子仿写。复习积压超过60词时，应用提示优先处理复习；不为打卡追求速度。不把“看过”当作“已经会了”。

## 使用

网页部署后，用手机浏览器打开网址。是否支持“安装”或“添加到桌面”以浏览器菜单为准。第一次在线加载后会尝试缓存应用资源；浏览器清缓存会移除离线资源和学习记录。

本机开发预览（需要 Node.js，无第三方运行依赖）：

```sh
npm start
```

打开 `http://127.0.0.1:4173`。预览服务器仅监听本机回环地址，不是手机远程访问入口。把 `dist/` 部署到任意HTTPS静态托管服务即可从手机访问。GitHub Pages工作流已附带，需要在用户指定的仓库启用Pages的GitHub Actions部署后使用。

也可直接打开 `dist/index.html`，但浏览器对 `file:` 的存储、离线缓存、下载和朗读支持不一；推荐通过HTTPS或本机预览服务使用。

## 已实现的训练

- 隐藏释义，先回忆后翻卡；“没想起来／模糊／记住了”反馈。
- 间隔阶梯1、2、4、7、15、30天；成功检索逐级推进，遗忘缩短间隔并重试。
- 错词离开页面后保留；当天重试未完成不能打卡；次日到期继续复习。
- 拼写检索与四选一词义测试，优先已学词；自测不虚增已学数量。
- 20词基础补漏，错词优先加入新词计划；可搜索全部来源词、显示基础词、收藏、标记已会。
- 42天学习日历，按设备本地日期记录打卡；日期回拨会提示校正。
- 42篇原创训练范文，英文逐句点读与整篇顺序朗读、逐段翻译、结构拆解、表达迁移、学习笔记。
- 6篇有研究或官方来源支撑的学习方法短文。
- JSON备份、文本备份和严格校验的恢复；默认不联网同步个人进度。

间隔安排是学习策略，不是个人记忆率的精确模型，不保证某次考试分数。图中的遗忘曲线只是原理示意。

## 词库与作文来源

词库来自GitHub开源项目 [ECDICT](https://github.com/skywind3000/ECDICT)，固定版本和原始文件SHA-256见 `dist/data/meta.js`，完整许可见 `THIRD_PARTY_NOTICES.md`。词库有5,329条高中／四级来源词；默认隐藏1,784条基础词，仍可查看并补学。

四级标签规范合并后3,848条、高中标签3,676条。它是该来源标签词的全集，不宣称覆盖所有现行四级考试词。700个重点词按通用语料频率及来源标签筛选，不是经过真题语料统计的高频榜。具体处理见 `词库说明.txt`。

作文以公开考试要求和常见主题为参考，由本项目原创，非转载网络范文、官方标准答案或押题。每篇正文120–180词，参考链接在文章底部。正文词数以项目的英文词分割规则统计，考试人工计数可能略有不同。
